# Mohamed Ali Lahmer — Portfolio

A responsive, bilingual (English/French) Cloud & DevOps portfolio made with plain HTML, CSS and JavaScript. It is designed to be hosted for free with GitHub Pages.

## 1. Personalize before publishing

1. Open `index.html`.
2. Replace each project link that currently points to `https://github.com/medalilahmar` with the exact repository URL for that project, when available.
3. Add your CV PDF at `assets/cv.pdf`. Keep that exact filename, or update the two CV links in `index.html`.
4. Add your professional email or LinkedIn URL to the Contact section if you want them displayed.
5. Review project descriptions and skill tags to ensure they accurately reflect your work and experience.
6. Optional: update the `<meta name="description">` text in `index.html`.

## 2. Publish on GitHub Pages (free)

1. Sign in to GitHub and create a **public** repository named exactly `medalilahmar.github.io`.
2. Upload the contents of this folder to the repository root. Do not upload the ZIP file itself as the website.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes, then visit: `https://medalilahmar.github.io`

If your GitHub username is different, replace `medalilahmar` in the repository name and website URL with your actual username.

## 3. Preview locally

Open `index.html` in a browser. The site uses Google Fonts when internet access is available; the layout still works if fonts cannot load.

## Files

- `index.html` — website content and sections
- `style.css` — responsive styling
- `script.js` — English/French language switch and mobile menu
- `assets/cv.pdf` — put your CV PDF here

## Notes

- No paid services, backend, database, framework or build process is required.
- GitHub Pages is suitable for static websites. Do not place passwords, API keys, private reports or sensitive personal information in a public repository.
